# Personal Wellness App

A private, secure wellness web app designed for women - featuring period tracking, habit management, vision boards, journaling, and more.

## ✨ Features

- **🔐 Secure Authentication**: Google OAuth + Magic link email sign-in
- **📱 Personalized Dashboard**: Daily greeting with quick actions
- **✅ Task Management**: To-dos with priorities and due dates
- **🌸 Period Tracking**: Calendar with flow, mood, and symptoms
- **🎯 Habit Tracking**: Daily habits with streak counters
- **🖼️ Vision Board**: Visual goal setting with cloud storage
- **📝 Digital Journal**: Daily entries with mood integration
- **🔔 Smart Reminders**: Custom notifications
- **🔒 Privacy Controls**: App lock, data export, account deletion

## 🚀 Getting Started

### Prerequisites
- Node.js 16 or higher
- npm or yarn

### Installation

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Set up environment**:
   Copy `.env.example` to `.env` and add your Supabase credentials

3. **Set up database**:
   Run the SQL schema in `supabase-schema.sql`

4. **Start development server**:
   ```bash
   npm run dev
   ```

5. **Open**: `http://localhost:5173`

### Build for Production
```bash
npm run build
```

## 🛡️ Privacy & Security

Your wellness data is completely private and secure:
- **End-to-end encryption** for all personal data
- **Row-level security** - only you can access your data
- **Optional app lock** with PIN protection
- **Full data export** in JSON format
- **Complete account deletion** when needed
- **No data sharing** with third parties

3. Use like a native app - even works offline!
